# 🎤 Contrôle Vocal - AnalyzeIt

## Fonctionnalités

✅ **Navigation vocale** entre les pages  
✅ **Contrôle des prédictions** par la voix  
✅ **Interface intuitive** avec feedback visuel  
✅ **Support multilingue** (français)  
✅ **Accessible** et compatible lecteurs d'écran  

## Commandes rapides

### Navigation
```
"Accueil" → Page d'accueil
"Prédictions" → Page des prédictions
```

### Prédictions
```
"Date de début demain" → Définit la date de début
"Date de fin dans 30 jours" → Définit la date de fin
"Pays France" → Sélectionne la France
"Afficher les prédictions" → Lance l'analyse
```

## Démarrage rapide

1. **Ouvrez** l'application dans Chrome/Edge
2. **Autorisez** l'accès au microphone
3. **Cliquez** sur le bouton flottant 🎤
4. **Parlez** votre commande
5. **Attendez** la confirmation visuelle

## Compatibilité

| Navigateur | Support |
